# 公投與在地

網站：https://hardy1yang.github.io/referendum-atlas/

2018、2021、2022、2025 年 16 案全國性公投在全國 7,751 個村里的結果：住得離核電廠、燃煤電廠與天然氣接收站多近，同意率有沒有不同；以及把村里加總到第 9–11 屆立委選區後，與立委的議題發言關注、第 11 屆核能修法記名表決和 2025 年罷免並列。所有結果都是村里或選區的聚合資料，不推論個人投票。

這個 repository 只放建置好的靜態網站與一份公開資料包。

- 資料版本（run）：`b0067efb43a0`，產製 2026-10-08T17:33:06Z，部署 2026-10-09T01:31:01+00:00
- 立委資料：LY-decomposition run `fetch-20261006T122600Z-dfc47335`（https://hardy1yang.github.io/ly-issue-atlas/）
- 村里對照：四個投票日各縣市投票權人涵蓋率最低 100.0%；7,751 個村里依兩版村里界分成 7,400 個異動群組
- 能源設施：11 處（核電 4、燃煤 6、天然氣接收站 1），位置取自 OpenStreetMap

## 方法摘要

- 同意率＝同意票 ÷ 有效票；距離為村里代表點到最近設施的直線距離，分 0–5、5–10、10–20、20–50、50 公里以上五段。
- 第一章：各案距離分段的加權同意率（鄉鎮市區重抽區間）、第 16、17、21 案的村里固定效果追蹤模型，電廠附近只涵蓋少數鄉鎮時另以全國鄉鎮的對照比較判斷是否特殊，以及與能源無關的第 10、13、18 案對照檢驗。
- 第二章：選區同意率偏離全國的幅度與立委議題發言比例的關聯（關注，不是立場）、2025 年 5 月 13 日核管法第六條修正全案表決與選區第 21 案有效票多數方向的比較、2025 年 31 案罷免並列。
- 政黨親向：以 2016、2020、2024 年不分區政黨票描述村里政黨傾向，計算各案被政黨解釋的程度，並把第一、二章的結果以控制政黨前／後並列。

## 限制

- 所有結果都是村里或選區的聚合資料，只能描述「某類村里的同意率較高」，不能推論個人怎麼投。
- 各案的門檻、投票日、是否與選舉同日與題目寫法都不同，跨案比較只代表相對位置的變化，不等於態度改變。
- 距離以村里代表點到設施的直線距離計算；對照案（同婚、東奧正名、萊豬）也出現同量級的橫斷面差異，距離可能同時代表城鄉與其他在地差異，第一章以村里內追蹤結果為主。
- 立委的議題關注取自 LY-decomposition 的發言分類，不含立場；第一層只描述關注與選區民意強度的關聯。
- 第 11 屆核管法表決完全依政黨分立，選區有效票多數與表決是否一致主要反映政黨與選區組成的對應；選區有效票多數也不等於選民多數（第 21 案投票率約一到五成）。
- 村里對照以 114 年版村里界為基準，2018–2021 年的整併與 2025 年後的拆分以兩版村里界重疊分組合併呈現。
- 政黨親向以投票前最近一次立委選舉的不分區政黨票描述；控制政黨可能連帶扣掉真正的在地差異，不控制則可能把政黨重組誤當成距離效果，網站兩種結果並列。「超出政黨預期」是描述性的殘差，不是因果效果。
- 桃園市第5選舉區罷免案的投開票所表與中選會新聞稿相差 72 票，該案只呈現選區總數。
- 2025 年罷免的村里層級，本站只取得桃園市的投開票所結果表；其餘案件只呈現選區總數。

## 中立的呈現方式

網站不使用政黨代表色；色彩只代表同意率、與全國的差距或投票率，政黨以文字標示，案名照中選會公告主文。
